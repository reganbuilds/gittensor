Step-by-step setup

Get the Kalshi Weather
Arb Bot running locally

This guide walks you through downloading the bot files, installing Python, and running the paper trading engine with the live dashboard — all on your own machine.

1
Download the bot files
Get everything from Claude onto your computer

Download all six files from the Claude conversation above. You'll need to create a folder to keep them organized.

💡 Make a folder called kalshi_bot anywhere on your computer — Desktop, Documents, wherever you prefer. Then download all files into it, keeping the subfolder structure.

Your folder should look exactly like this:

kalshi_bot/
  ├── run.py                 ← start here
  ├── requirements.txt
  ├── bot/
  │   ├── engine.py         ← bot brain
  │   └── server.py         ← API server
  └── dashboard/
       └── index.html      ← dashboard
⚠️ Do not put engine.py or server.py directly in the root — they must be inside a bot/ subfolder. The bot creates a data/ folder automatically when it first runs.
2
Install Python 3.10+
Skip this step if you already have Python installed

Check if Python is already installed by opening a terminal and running:

Terminal / Command Prompt 
python3 --version   # Mac / Linux
python --version    # Windows

If you see Python 3.10.x or higher, skip to Step 3. If you get an error or see Python 2.x, install Python:

🍎 Mac: The easiest way is to install via the official installer at python.org/downloads — download the macOS package and run it. Alternatively, if you have Homebrew: brew install python3
Terminal — Homebrew (if you have it)
brew install python3
🪟 Windows: Download the installer from python.org/downloads. On the first screen, check "Add Python to PATH" before clicking Install — this is critical.
⚠️ After installing on Windows, use python instead of python3 and pip instead of pip3 throughout this guide.
Terminal — Ubuntu / Debian
sudo apt update && sudo apt install python3 python3-pip -y

Verify it worked:

Terminal
python3 --version
# Should print: Python 3.10.x or higher
3
Open a terminal in the bot folder
Navigate to where you saved the files

On Mac, open Terminal (search Spotlight for "Terminal"), then navigate to your folder:

Terminal
cd ~/Desktop/kalshi_bot   # if saved to Desktop
# or
cd ~/Documents/kalshi_bot # if saved to Documents
💡 Shortcut: In Finder, right-click the kalshi_bot folder and choose "New Terminal at Folder" — this opens a terminal already in the right place.

On Windows, open the kalshi_bot folder in File Explorer, then click the address bar, type cmd, and press Enter. Or open Command Prompt and navigate:

Command Prompt
cd C:\Users\YourName\Desktop\kalshi_bot
Terminal
cd ~/kalshi_bot

Confirm you're in the right place:

Terminal 
ls   # Mac / Linux — should show run.py, bot/, dashboard/
dir  # Windows

Now install the three required Python packages:

Terminal — install dependencies
pip3 install flask flask-cors requests
# Windows: use  pip install flask flask-cors requests
💡 If you get a permissions error on Mac/Linux, add --user to the end: pip3 install flask flask-cors requests --user

You should see output ending in Successfully installed flask flask-cors requests. That's it — no other packages needed.

One command launches everything

From inside the kalshi_bot folder in your terminal, run:

python run.py    # Windows

5
Open the dashboard
Your live paper trading monitor

With the bot running in the terminal, open the dashboard in your browser:

Terminal — open dashboard (new tab)
open dashboard/index.html

Or manually: open Finder → navigate to kalshi_bot/dashboard/ → double-click index.html

Command Prompt
start dashboard\index.html

Or manually: open File Explorer → navigate to kalshi_bot\dashboard\ → double-click index.html

Terminal
xdg-open dashboard/index.html

The dashboard polls the bot's API at http://localhost:5000 every 5 seconds and updates automatically. You'll see:

  • ✦ Dashboard tab — bankroll, P&L, win rate, open positions, P&L chart
  • ✦ Live signals tab — every city's GFS forecast vs Kalshi price, edge highlighted in green
  • ✦ Trade log tab — full history of paper trades with entry, exit, and P&L
  • ✦ Bot logs tab — raw terminal output from the Python engine
💡 If the dashboard shows "Demo mode" in amber, the bot server isn't reachable. Make sure python3 run.py is still running in your terminal and try refreshing the page.
6
Understand the output
What the numbers mean

Here's what each metric in the dashboard tells you:

  • ✦
    Edge % — the gap between GFS forecast probability and Kalshi's price. A 12% edge means the bot thinks the true probability is 12 cents higher than what Kalshi is pricing.
  • ✦
    BUY YES — bot thinks Kalshi is underpricing the event happening. You'd buy YES contracts.
  • ✦
    BUY NO — bot thinks Kalshi is overpricing the event. You'd buy NO contracts (essentially shorting YES).
  • ✦
    Win rate — % of settled trades that were profitable. Expect 50–65% with real forecast data. Higher edge = higher win rate.
  • ✦
    Open positions — paper trades currently active, waiting for Kalshi to settle them.
  • ✦
    Simulated vs live forecast — check the Bot Logs tab. If you see "simulated forecast" it means the Open-Meteo API was unreachable; the bot still runs using realistic seasonal estimates.
ℹ️ The paper trading simulation settles positions after 6–10 hours with a win probability proportional to the edge found. In live trading, Kalshi settles at midnight based on the NWS Daily Climate Report.
7
Go live with real money (optional)
Only do this after paper trading shows consistent profit
🚨 Only proceed when your paper trading win rate is above 55% consistently for 2+ weeks. Real money trading carries real risk of loss.

To connect to real Kalshi markets, you need an API key:

  • 1 Go to kalshi.com → sign in → Settings → API
  • 2 Create a new API key and copy it
  • 3 Open bot/engine.py in a text editor
  • 4 Find the fetch_kalshi() function and add your key to the headers
bot/engine.py — add your API key here
def fetch_kalshi(prefix):
    try:
        r = requests.get(
            f"{KALSHI_BASE}/markets",
            params={"series_ticker": prefix, "status": "open"},
            headers={
                "Authorization": "Bearer YOUR_API_KEY_HERE"
            },
            timeout=8
        )

To place real orders, you'll also need to implement the order endpoint in engine.py. The Kalshi docs are at docs.kalshi.com — look for POST /portfolio/orders.

⚠️ Start with a small real-money bankroll (e.g. $100–$200) and small stakes ($5–$10/trade) before scaling up. Verify the live win rate matches your paper trading results.
